    06 — Key Insights
    Synthesized Findings
    What the Data Tells You
    🤖
    GenAI is #1 by volume
    132 questions — 18% of all questions — are GenAI / LLM related. RAG alone accounts for 61 of them. This is the single biggest prep area.
    🐍
    Python is mostly Medium-Hard
    Python has 112 questions but only 19 are Easy. 85 are Medium and 8 are Hard — interviewers go deep on Pandas, strings, and OOP concepts.
    📉
    Maths for ML: 0% pass rate
    All 15 Maths for ML questions appeared in rejected interviews. This is a critical prep gap — learners clearly struggle when math-heavy topics are probed.
    💬
    NLP has the highest clear rate
    12 of 14 NLP questions came from cleared/offered rounds (86%). NLP interview prep is yielding results — learners are well-prepared here.
    ⚙️
    Fine-Tuning LLMs is Hard-skewed
    7 of 11 Fine-Tuning questions are classified Hard. LoRA, quantization, PEFT and evaluation — these need dedicated depth prep.
    💻
    SQL and Python dominate coding
    Together, Python (37) + SQL (32) account for 71% of all coding questions. If learners can't code in these, they'll fail assessments.
    🏢
    Citius Tech is the #1 interviewer
    67 questions from Citius Tech alone — nearly 2x the next company. Their process is well-documented and highly prep-able.
    🎯
    AI Engineer is the #1 target role
    115 questions for AI Engineer roles — this is the most active hiring position. GenAI, Python, and LLM integration are the core skillset required.
    📊
    79% questions are conceptual
    574 of 727 questions require explanation, not code. Strong verbal + written communication of ML concepts is as important as coding ability.
